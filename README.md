# LSTU CLI

Терминальный интерфейс личного кабинета ЛГТУ на Textual. Сверху расположен журнал ответов, снизу — поле команд.

## Запуск

Из корня проекта:

```powershell
python app.py
```

При старте откроется форма входа. Логин можно сохранить и выбрать при следующем запуске; пароль всегда вводится заново. Логины находятся в `.lstu_accounts.json`.

Для JS-загружаемого расписания также нужен установленный Google Chrome. Он
запускается как скрытый headless-процесс, когда нужно дождаться таблицы или
индикатора текущей недели, и автоматически закрывается после получения данных.

## Команды

| Команда | Назначение |
| --- | --- |
| `help` | список команд |
| `me` | данные профиля и обучения |
| `semesters` | выбрать семестр стрелками и открыть его клавишей Enter |
| `subject` / `open subject` | выбрать предмет уже открытого семестра |
| `today` / `schedule today` | пары на сегодня с учётом текущей недели сайта |
| `tomorrow` / `schedule tomorrow` | пары на завтра с учётом текущей недели сайта |
| `links` | доступные имена ссылок |
| `clear` | очистить журнал |
| `logout` | снова показать форму входа |
| `quit` / `exit` | закрыть программу |

Горячие клавиши: `Ctrl+L` — очистка, `Ctrl+C` — выход.

## Устройство Python-кода

`Lstu_parser.py` выполняет HTTP-запросы и разбирает HTML. `app.py` отвечает за Textual, команды и форматирование вывода.

### Предметы

После выбора семестра приложение выводит расписание и список предметов. Затем
введите `subject` (либо `open subject`), выберите предмет стрелками и
подтвердите Enter — его URL передаётся в `LstuParser.open_subject(url)`.
Предмет открывается отдельным экраном: сверху файлы,
посередине поля загрузки, снизу сообщения преподавателя. `Esc` возвращает к
основному окну.

Каждый из трёх блоков предмета прокручивается независимо. Нажмите `D`, чтобы
выбрать и скачать материал преподавателя или ранее прикреплённый файл работы;
файл сохранится в папку `.\downloads` рядом с приложением.

На экране предмета нажмите `U`, чтобы прикрепить файл к работе. Выберите доступную работу, затем либо введите полный путь к файлу, либо нажмите кнопку «Выбрать файл» для системного диалога. `Ctrl+Enter` отправляет файл, `Esc` возвращает к предмету. Загрузка выполняется через скрытый Chrome, поэтому отдельное окно браузера не появляется.
